# Agente Personal de Notificaciones

Un agente de notificaciones personal desarrollado en Python. 
Este proyecto se encarga de gestionar notificaciones, recopilar información mediante scrapers o APIs, y proporcionar una interfaz de usuario intuitiva.

## Estructura del Proyecto

- `core/`: Contiene la lógica central y base del sistema.
- `gui/`: Contiene los elementos de la interfaz de usuario.
- `tools/`: Contiene los scrapers, integraciones con APIs externas y utilidades adicionales.
